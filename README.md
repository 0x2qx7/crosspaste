# CrossPaste

Общий буфер обмена для быстрой передачи форматированного текста, кода, фотографий и файлов между своими устройствами (ПК, телефон, ноутбук) в реальном времени.

Без сторонних облаков, без принудительной регистрации и без ограничений.

---

## Возможности

- **Редактор текста**: визуальное форматирование (жирный, курсив, заголовки, списки, ссылки) и отдельный чистый режим «Код» с поддержкой `Tab`.
- **Фото и галерея**: загрузка и просмотр изображений (PNG, JPEG, WebP, GIF), копирование прямо в буфер в 1 клик.
- **Хранилище файлов**: быстрая передача файлов любого типа и размера.
- **Полноэкранный Drag-and-Drop**: перетаскивание файлов прямо в окно браузера с любого экрана.
- **История и шаблоны**: история буфера, закреплённые заметки и каталог быстрых терминальных команд.
- **Темы и масштаб**: автоматическая, светлая и тёмная темы, масштабирование шрифта от 80% до 180%.
- **Синхронизация в реальном времени**: моментальное обновление на всех открытых устройствах через SSE (Server-Sent Events).

## Быстрый старт (Docker)

```bash
git clone https://github.com/0x2qx7/crosspaste.git
cd crosspaste
bash install.sh
```

Либо вручную:
```bash
cp .env.example .env
docker compose up -d --build
```

Приложение будет доступно по адресу: **`http://localhost:8089`** (или IP вашего сервера).

---

## Обновление

Для обновления до актуальной версии выполните:

```bash
bash update.sh
```

Скрипт автоматически:
1. Загружает свежий код из git (`git pull`).
2. Создаёт резервную копию базы данных и настроек в `backups/`.
3. Пересобирает и перезапускает контейнер без потери данных.

## Настройка HTTPS / Reverse Proxy

Для работы прямого копирования фото в мобильных браузерах рекомендуется настроить HTTPS через ваш обратный прокси:

### Nginx
```nginx
server {
    server_name paste.yourdomain.com;

    location / {
        proxy_pass http://127.0.0.1:8089;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

        # Для поддержки Server-Sent Events
        proxy_set_header Connection '';
        proxy_buffering off;
        proxy_cache off;
        chunked_transfer_encoding off;
    }

    client_max_body_size 0; # без ограничений на размер файлов
}
```

### Caddy
```caddyfile
paste.yourdomain.com {
    reverse_proxy 127.0.0.1:8089
}
```

## Конфигурация (.env)

Настройки задаются в файле `.env` (образец — `.env.example`):

| Переменная | По умолчанию | Описание |
|---|---|---|
| `HOST_PORT` | `8089` | Порт на сервере |
| `OPTIONAL_ACCESS_TOKEN` | *пусто* | Ключ доступа для входа (если пусто — без пароля) |
| `TEXT_CHARACTER_LIMIT` | `0` | Лимит символов текста (0 = безлимит) |
| `FILE_SIZE_LIMIT_MB` | `0` | Лимит размера файлов в МБ (0 = безлимит) |
| `IMAGE_SIZE_LIMIT_MB` | `0` | Лимит размера фото в МБ (0 = безлимит) |
| `CONTENT_EXPIRY_HOURS` | `0` | Автоочистка данных в часах (0 = отключено) |

## Резервное копирование

Все данные хранятся в папке `./data` (база данных SQLite, файлы и фото).

Для создания архива:
```bash
tar -czf backup-$(date +%Y%m%d).tar.gz data .env
```
